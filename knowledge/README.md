# knowledge

Vet / buy / import playbooks for a used car bought in the EU (researched Oct–Nov 2026). Every file carries a dated banner and V/A/I tags (verified / anecdotal / inferred): prices, laws and tool behaviour drift, so re-check before acting.

| file | use it for |
|---|---|
| [vin-sources.md](vin-sources.md) | which VIN/plate checks apply per country and brand, costs, control-lookup rule |
| [battery-soh.md](battery-soh.md) | battery-health evidence ranking, asks, DIY OBD, 12 V; PHEV/HEV/ICE equivalents |
| [pr-codes-vag.md](pr-codes-vag.md) | VW-group option codes, the 7-language sticker ask, options from photos |
| [coverage-rules.md](coverage-rules.md) | recalls, warranty country rule, goodwill, consumer law, used-car guarantees |
| [residual-risk.md](residual-risk.md) | judging known model flaws per VIN after coverage (money vs breakdown risk) |
| [buy/doc-verify.md](buy/doc-verify.md) | cross-checking inspection/service/battery documents, spec table |
| [buy/contract-checklist.md](buy/contract-checklist.md) | reviewing a purchase order (DE dealer in depth) |
| [buy/deposit-payment.md](buy/deposit-payment.md) | deposit line, dealer identity checks, SEPA Instant + VoP, scam patterns |
| [buy/pickup-day.md](buy/pickup-day.md) | before travel, at the car, paperwork, after |
| [buy/shutdown.md](buy/shutdown.md) | closing the hunt once a deal is signed |
| [import/README.md](import/README.md) | import module: destination guide + seller-country guides; how to add a destination |

Order of use: vet (vin-sources → battery-soh → coverage/residual-risk → doc-verify) → visit-ready gate (`carhunt evidence CAR`) → buy (contract → deposit → pickup) → import → shutdown.
